Panduan Integrasi Google Apps Script

Salin kode di bawah ini ke editor **Google Apps Script** dari Google Spreadsheet Anda.

Langkah Pemasangan Google Apps Script:

  1. Buka Google Sheets Anda → Pilih Menu Ekstensi → Pilih Apps Script.
  2. Hapus semua isi file `Code.gs` bawaan, lalu **paste** kode di atas.
  3. Klik **Terapkan (Deploy)** di pojok kanan atas → **Terapkan Sebagai Web App**.
  4. Ubah **Akses Siapa Saja (Who has access)** menjadi "Siapa Saja" (Anyone).
  5. Klik **Deploy**, salin **URL Web App**, lalu masukkan ke Pengaturan URL di aplikasi ini.
