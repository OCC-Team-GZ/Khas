Integrasi Google Spreadsheet

Masukkan Webhook Google Apps Script untuk sinkronisasi transaksi otomatis ke Google Spreadsheet secara online.

Kode Apps Script (Code.gs)

Salin kode berikut lalu tempel pada editor Google Apps Script di Spreadsheet Anda:

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    var timestamp = new Date();
    
    sheet.appendRow([
      timestamp,
      data.type || 'Transaksi',
      data.memberName || data.donorName || data.category || '-',
      data.amount || 0,
      data.note || '-'
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Petunjuk Integrasi Spreadsheet:

  1. Buka Google Sheets > Ekstensi > Apps Script.
  2. Hapus isi bawaan, lalu klik tombol Salin Kode .gs di atas dan tempel di editor Google.
  3. Klik Terapkan (Deploy) > Penerapan Baru (New Deployment).
  4. Pilih Jenis: Aplikasi Web (Web App).
  5. Akses (Who has access): Pilih Siapa Saja (Anyone).
  6. Klik Terapkan, salin URL Web App lalu tempel di kolom atas & klik tombol Tes Koneksi.
